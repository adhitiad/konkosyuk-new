# Administrasi Platform

Administrator memantau seluruh penyewaan dan menjalankan pengaturan serta tugas operasional platform.

## Spesifikasi

### Tujuan

Administrator dapat memantau seluruh aktivitas penyewaan dan menjalankan tugas operasional platform dari satu tempat, sehingga operasional tetap terkendali dan setiap menu administrasi mudah dijangkau.

### Selesai bila

- Administrator dapat membuka dashboard admin yang menampilkan ringkasan data platform.
- Administrator dapat masuk ke setiap menu administrasi: Pantau Booking, Kelola Pengguna, Verifikasi & Audit, dan Konfigurasi Platform.
- Seluruh halaman administrasi hanya dapat diakses oleh pengguna dengan peran admin; pengguna lain tidak akan melihat menu ini.

## Sub-fitur: Dashboard Admin

Admin melihat ringkasan data dan masuk ke menu administrasi platform.

### Tujuan

Memberi admin gambaran ringkas kondisi platform dan menjadi pintu masuk ke menu administrasi lainnya.

### Selesai bila

- Setelah masuk sebagai admin, halaman dashboard menampilkan ringkasan angka penting seperti jumlah properti, booking, pengguna, dan pendapatan.
- Dari dashboard dapat dibuka menuPantau Booking, Kelola Pengguna, Verifikasi & Audit, serta Konfigurasi Platform.
- Jika akun tidak memiliki peran admin, dashboard tidak dapat diakses dan pengguna dialihkan ke halaman sesuai perannya.

## Sub-fitur: Pantau Booking

Menampilkan seluruh booking di platform untuk dipantau oleh admin.

### Tujuan

Memungkinkan admin melihat seluruh booking yang terjadi di platform untuk memantau jalannya penyewaan.

### Selesai bila

- Admin dapat membuka halaman Pantau Booking yang memuat daftar semua booking.
- Setiap booking menampilkan informasi penting: nama penyewa, properti/unit, tanggal, status persetujuan, dan status pembayaran bila tersedia.
- Tersedia pencarian atau penyaringan daftar berdasarkan status atau kata kunci untuk memudahkan pemantauan.

## Sub-fitur: Kelola Pengguna

Admin mengelola akun serta hak akses pengguna di platform.

### Tujuan

Memberi admin kemampuan untuk melihat dan mengelola akun pengguna beserta peran aksesnya.

### Selesai bila

- Admin dapat melihat daftar seluruh akun pengguna beserta perannya (penyewa, pemilik, admin).
- Admin dapat mengubah peran atau status aktif akun dan perubahan langsung tersimpan serta tampil di daftar.
- Admin dapat mencari pengguna berdasarkan nama atau surel.

## Sub-fitur: Verifikasi & Audit

Sistem mencatat verifikasi dokumen, inspeksi, laporan perawatan, dan jejak audit untuk admin.

### Tujuan

Menyediakan satu area bagi admin untuk meninjau catatan verifikasi dokumen, inspeksi, laporan perawatan, dan jejak audit.

### Selesai bila

- Admin dapat membuka halaman Verifikasi & Audit yang memuat daftar verifikasi pengguna (KYC), inspeksi properti, dan laporan perawatan/kerusakan.
- Admin dapat membuka detail setiap catatan untuk melihat status, tanggal, dan informasi terkait.
- Admin dapat mengakses daftar jejak audit yang mencatat aktivitas penting di platform.

## Sub-fitur: Konfigurasi Platform

Admin mengubah konfigurasi dan pengaturan umum aplikasi.

### Tujuan

Memungkinkan admin mengubah pengaturan umum aplikasi sesuai kebutuhan operasional platform.

### Selesai bila

- Admin dapat membuka halaman Konfigurasi Platform.
- Admin dapat mengubah nilai konfigurasi yang tersedia dan menyimpannya; perubahan langsung berlaku di aplikasi.
- Sistem menampilkan pemberitahuan bahwa penyimpanan konfigurasi berhasil.
